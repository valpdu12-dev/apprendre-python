# Variables et affichage

Bienvenue dans ton premier cours de Python ! 🐍

## Afficher un message

La fonction `print()` affiche du texte à l'écran :

```python
print("Bonjour le monde !")
```

## Créer une variable

Une **variable** est une boîte dans laquelle on stocke une valeur :

```python
prenom = "Alice"
age = 15
print(prenom)
print(age)
```

En Python, pas besoin de déclarer le type : il est deviné automatiquement.

## Règles de nommage

- Un nom de variable commence par une lettre ou `_`
- Pas d'espace : on utilise `_` (ex: `mon_prenom`)
- Pas de mot réservé (`if`, `for`, `print`…)

## À retenir

> `print()` affiche, `=` stocke une valeur dans une variable.

 essaie l'exercice **« Bonjour le monde »** pour pratiquer !
