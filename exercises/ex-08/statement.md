## Objectif

Écrire une fonction `division_securisee(a, b)` qui :

- retourne `a / b` si la division est possible
- retourne la chaîne `"division impossible"` si `b` vaut `0` (utilise `try` / `except ZeroDivisionError`)

## Exemples

```python
division_securisee(10, 2)   # 5.0
division_securisee(10, 0)   # "division impossible"
```
